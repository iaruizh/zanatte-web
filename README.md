# Zanatte — Web Oficial

Sitio web oficial de Zanatte Centro Holointegrativo.

**Stack:** Next.js 15.3.6 · React 19 · TypeScript · Tailwind CSS 4

## Estructura

```
zanatte-web/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── components/
│   └── sections/
│       ├── NavBar.tsx
│       ├── HeroSection.tsx
│       ├── FilosofiaSection.tsx
│       ├── ExperienciasSection.tsx
│       ├── RuahSection.tsx
│       ├── SobreIvanSection.tsx
│       ├── TestimoniosSection.tsx
│       ├── ContactoSection.tsx
│       └── Footer.tsx
└── public/
    └── images/
        ├── logo-zanatte.png        ← Logo verde horizontal
        ├── logo-zanatte-blanco.png ← Logo blanco para footer
        └── ivan-ruiz-hero.jpg      ← Foto de Iván
```

## Imágenes requeridas

Subir a `public/images/`:
- `logo-zanatte.png` → Logotipo_NEGCOLOR_Verde_HZ.png
- `logo-zanatte-blanco.png` → Logotipo_NEGBN_Blanco_HZ.png
- `ivan-ruiz-hero.jpg` → Foto profesional de Iván
- `og-zanatte.jpg` → 1200x630px para redes sociales

## Deploy

Conectar repositorio en Vercel y hacer deploy automático.
